## Architecture & Critical Width / Semantic Guarantees

1. **ISA hooks (`x64Gpr : GprIsa Reg64 RegMm CondCode Directive`)**:
   - Reuses `x64CondReads`, `x64NegCond`, and `x64Scratch := [.r10, .r11]` from `LeanQbe.T.Amd64.Base` (`x64Mach`).
   - `zeroFlags := [.c, .o]`; `clearFlags := [ins32 (.xor (.reg (d .r10)) (.reg (d .r10)))]` (`flag_clob = maskAll`).
   - `mov` uses `movq` (`maskNone`), `movi` uses `mov $c, %rd` (never `xor $0`, preserving flags with `maskNone`), `setcc` emits `setcc + movzbl` (`maskNone`), `jmp` / `jcc` use direct jumps, and `jnzGpr` emits `testb %r_b, %r_b; jnz l` (`maskAll`).
2. **Pitfall `(a)` — `.bool` low-byte discipline**:
   - All `.bool` register consumers (`jnzGpr`, `select`, `ofBool`, `opBoolBin`/`opBoolNot`, `x64SetupCf` for `addc`/`subb` GPR carry/borrow-in, `x64Store .bool`) read `b8 r` only so arbitrary junk in bits `8..63` is ignored. `load .bool` emits `movzbl` and `loadVal` rejects bytes `∉ {0, 1}`.
3. **Pitfall `(b)` — Sub-64 upper-bit discipline**:
   - Operations on `.bits n` (`n ∈ [8, 16, 32, 64]`) either operate at exact width `w` (`8`/`16`/`32`/`64`) or zero/sign-extend `8`/`16` operands to `32`-bit first (`udiv/sdiv/urem/srem`, `cmovcc` at `.W32`/`.W64`, `zext`/`sext`).
4. **Pitfall `(c)` — X64 shift-mask discrepancy (`Kraken/X64/Semantics.lean`)**:
   - Because Kraken X64 masks `.W8`/`.W16`/`.W32` shift counts by `0x1f` while `OpCode.{shl,lshr,ashr}` masks by `n`, variable `8`/`16`-bit shifts save/restore `%rcx` via `.r10` and emit `andl $7, %ecx` / `andl $15, %ecx`. Immediate shifts reduce counts modulo `n`, folding `% n == 0` to `opCopyBits` (`maskNone`). Rotates propagate `maskCF ||| maskOF` for demonic multi-bit `OF`.
5. **1-for-1 Opcode & Variant Coverage (`x64Op_supportsScalarOp`, `x64SupportsScalarOp_complete`)**:
   - `[8, 16, 32, 64]`: `copy/add/sub/mul/neg/and/or/xor/not/shl/lshr/ashr/rotl/rotr/ofBool`, `udiv/sdiv/urem/srem` (`rax`/`rdx` saved/restored), `cmp` (both `.flag` and `.gpr`), `select` (`cmovcc` with `.flag`/`.gpr`/`.imm` — never branching), `zext/sext/trunc/bitcast`, and `.bool` `copy/and/or/xor/not`.
   - `[16, 32, 64]`: `bswap` (`rolw $8`, `bswapl`, `bswapq`).
   - `[32, 64]`: `addc` (`.default` `adc`, `.adcx` `maskCF`, `.adox` `maskOF`), `subb` (`sbb`), `umulw` (`.default` `mul`, `.mulxFast` `maskNone`), `smulw`, `fshl/fshr` (`shld`/`shrd`).
   - Variant forms: `VariantHint.disp` (`lea`), `VariantHint.decInc` (`dec`/`inc`, `maskDecInc`), 2-address fast paths, immediate ops, and `[base]` / `[base+disp]` / `imm` addressing for `load`/`store`. Explicitly rejects `clz/cls/rbit/ctz/popcnt`, `udiv0/sdiv0`, floats, and vectors.
